# AI 辅助流量研判与告警研判：从 0 到精通

> 面向安全运营（SOC）/蓝队/安全分析师的实战教程：用 AI（LLM）把**流量研判**与**告警研判**从“人肉翻日志”变成“人机协同、可复用、可闭环”的工程能力。
> 全部内容基于**已授权环境 / 自有靶场 / 自有日志**，强调方法论、可复现命令与真实输出解读。

---

## 这是什么

很多企业不缺告警，缺的是**把告警变成结论**的人。本教程用一条主线串起来：

**原始告警/流量 → 上下文补全 → IOC 提取 → 时间线还原 → ATT&CK 映射 → 定性定级 → 处置建议 → 闭环**

并在每一步告诉你：**哪里该让 AI 做、哪里必须人拍板、怎么把原始数据喂给 AI 才不会翻车。**

不是“把日志丢给 ChatGPT”的玄学，而是**带约束、可审计、数据可不出域**的研判工程。

## 适用人群

- 刚进 SOC 的安全分析师（从“看不懂告警”到“能独立下结论”）
- 想用 AI 给团队提效的安全负责人（建工作流、接 SOAR）
- 红队/渗透测试想理解“蓝队怎么看我”的人（知己知彼）
- 对 Detection Engineering 感兴趣、想做误报治理的工程师

## 配套原则

1. **数据不出域优先**：涉及真实日志/流量，优先本地/私有化模型（第 13 章）。
2. **AI 下结论，人负最终责任**：AI 给“疑似/证据/建议”，分析师确认并签字。
3. **可复现**：所有命令、过滤表达式、输出片段都来自真实工具，可直接照跑。
4. **不越权**：本教程只讲**检测与研判**，不提供攻击载荷库；案例用靶场与模拟流量。
